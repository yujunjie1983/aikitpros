🧩 Workflow Graph

Single HTTP node wraps the full AikitPros campaign pipeline. No chaining required.

INPUT

brief

User's campaign prompt. e.g. Promote organic mango juice to Gulf moms. Optional lang, duration, engine.

HTTP NODE

POST /v1/campaign

Calls api.aikitpros.com. Auto-routes to Veo3 / Kling / Runway / Pika. Triple-tier fallback built-in.

OUTPUT

campaign

JSON: script, image_url, music_url, video_url, cost_usd, engine_used.

📋 HTTP Node Config

Method:  POST
URL:     https://api.aikitpros.com/v1/campaign
Headers:
  Authorization: Bearer {{#env.ACE_KEY#}}
  Content-Type:  application/json
Body:
  {
    "brief":    "{{#start.brief#}}",
    "lang":     "{{#start.lang#}}",
    "duration": {{#start.duration#}},
    "engine":   "auto"
  }
Timeout: 90s
